# Razorpay Payment Testing Guide

## Understanding Payment Verification

When you create an order with Razorpay, the verification signature is NOT generated by your backend. It comes from Razorpay after a successful payment.

### Flow:

1. **Create Order (Backend)** → Returns `razorpayOrder.id` and `razorpayKeyId`
2. **Open Razorpay Checkout (Frontend)** → User pays
3. **Razorpay Callback (Frontend)** → Receives `razorpay_payment_id` and `razorpay_signature`
4. **Verify Payment (Backend)** → Validates the signature

### Signature Generation

Razorpay generates the signature using:
```
HMAC_SHA256(razorpay_order_id + "|" + razorpay_payment_id, razorpay_key_secret)
```

## Testing Without Frontend Integration

### Option 1: Generate Test Signature (Node.js)

Create a test script to generate a valid signature:

```javascript
const crypto = require('crypto');

const razorpay_order_id = 'order_S070eZYZMnpi1r';
const razorpay_payment_id = 'pay_TestPayment123';  // Use any test payment ID
const razorpay_key_secret = 'Q9FQHLJGtA8knQPOmdTr7vpK';  // Your secret

const signature = crypto
  .createHmac('sha256', razorpay_key_secret)
  .update(`${razorpay_order_id}|${razorpay_payment_id}`)
  .digest('hex');

console.log('Generated Signature:', signature);
```

Save this as `generate_signature.js` and run: `node generate_signature.js`

### Option 2: Use Razorpay Test Mode

1. Go to https://dashboard.razorpay.com/
2. Switch to **Test Mode**
3. Use test card: `4111 1111 1111 1111`

## Example Test with Generated Signature

### Step 1: Create Order
```bash
POST /api/orders/create
```

Response:
```json
{
  "razorpayOrder": {
    "id": "order_S070eZYZMnpi1r"
  }
}
```

### Step 2: Generate Signature

Using the script above with:
- `razorpay_order_id`: `order_S070eZYZMnpi1r`
- `razorpay_payment_id`: `pay_TestPayment12345`  (any string)
- `razorpay_key_secret`: `Q9FQHLJGtA8knQPOmdTr7vpK`

Result: `Generated Signature: abc123...`

### Step 3: Verify Payment
```bash
POST /api/orders/verify
```

Body:
```json
{
  "razorpay_order_id": "order_S070eZYZMnpi1r",
  "razorpay_payment_id": "pay_TestPayment12345",
  "razorpay_signature": "abc123..."
}
```

## Common Errors

### "Payment verification failed"
- The signature doesn't match
- Make sure you're using the SAME payment_id in both signature generation and verification
- Make sure you're using the correct razorpay_key_secret

### "Payment verification is currently unavailable"
- Check that RAZORPAY_KEY_SECRET is set in .env
- Check that it's not a placeholder value

## Production Usage

In production, the frontend handles the Razorpay checkout:

```javascript
// Frontend (React/Vue/etc)
const options = {
  key: razorpayKeyId,  // From createOrder response
  amount: razorpayOrder.amount,
  currency: razorpayOrder.currency,
  order_id: razorpayOrder.id,
  handler: function(response) {
    // Razorpay automatically generates these:
    const { razorpay_order_id, razorpay_payment_id, razorpay_signature } = response;
    
    // Send to backend for verification
    fetch('/api/orders/verify', {
      method: 'POST',
      body: JSON.stringify({
        razorpay_order_id,
        razorpay_payment_id,
        razorpay_signature
      })
    });
  }
};

const razorpay = new Razorpay(options);
razorpay.open();
```

## Check Server Logs

When testing, check the server console for signature verification details:

```
Signature Verification: {
  received: 'f668dd85...',
  expected: '8a7b9c6d...',
  match: false,
  order_id: 'order_S070eZYZMnpi1r',
  payment_id: 'pay_NXj2k3l4m5n6o8'
}
```

This will help you debug signature mismatches.
